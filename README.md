# Video-File-Data-Corruptor

一个纯前端的视频文件底层数据修改工具：不做视觉特效，直接在二进制层面解析并修改 MP4 文件的 mdat 数据区。

## 项目特性
- **纯前端实现**：无需后端，直接在浏览器中读取文件并进行二进制处理。
- **无视觉特效**：不经过 Canvas 或 CSS 滤镜，直接篡改文件底层数据。
- **真实解码器反馈**：修改后的数据交由浏览器底层解码器解析，自然产生真实的比特翻转、绿屏和宏块错位等故障。
- **保证可播放且不改变视频长度**：结构完整保留，不缩短原视频时长，提供可调参数控制失真程度。

## 快速开始
1. 下载或克隆本项目。
2. 在浏览器中打开 `数据损坏器.html`。
3. 导入你的视频文件。
4. 调节“失真程度”滑块。
5. 点击“损坏并播放”，观察解码器产生的真实数据损坏效果。
6. 点击“下载损坏文件”保存处理后的视频。

## 技术原理
1. 利用 `ArrayBuffer` 直接读取视频文件的原始二进制数据。
2. 解析 MP4 容器结构（ftyp、moov、mdat 等盒子）。
3. 准确定位 mdat 数据区，保留文件头与关键帧结构。
4. 对 mdat 区域内的压缩数据执行比特翻转（Bit Flip）、字节抹零或块交换操作。
5. 生成新的 Blob 交给 video 标签播放。

# Video-File-Data-Corruptor

A pure frontend video file low-level data modifier tool: no visual effects, directly parsing and modifying the mdat data area of MP4 files at the binary level.

## Features
- **Pure Frontend**: No backend required. Reads and processes files directly in the browser.
- **No Visual Effects**: No Canvas or CSS filters. Directly tampers with the underlying binary file data.
- **Real Decoder Feedback**: Modified data is parsed by the browser's native decoder, naturally producing real bit flips, green screens, and macroblock misalignment.
- **Playability & Length Preserved**: Structure is fully retained, original video length is not shortened. Adjustable parameters control the degree of distortion.

## Quick Start
1. Download or clone this repository.
2. Open `数据损坏器.html` in your browser.
3. Import your video file.
4. Adjust the "Distortion Degree" slider.
5. Click "Corrupt and Play" to observe the real data corruption effects generated by the decoder.
6. Click "Download Corrupted File" to save the processed video.

## Technical Principles
1. Use `ArrayBuffer` to directly read the raw binary data of the video file.
2. Parse the MP4 container structure (ftyp, moov, mdat boxes).
3. Accurately locate the mdat data area, retaining the file header and keyframe structure.
4. Perform bit flips, byte zeroing, or block swapping on the compressed data within the mdat area.
5. Generate a new Blob and feed it to the `<video>` tag.
